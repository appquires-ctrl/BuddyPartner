# Workspace Customizations & Agent Rules

## Git Branch & Commit Policy
- **NEVER touch, commit to, or push to the `main` branch.**
- The `main` branch is the primary backup branch and must remain untouched.
- All feature development and bug fixes MUST be executed exclusively on the `dev` branch.
- **NEVER execute `git commit` or `git push` without explicit user permission.** Always ask the user and receive confirmation before committing or pushing changes.
