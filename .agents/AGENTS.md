# Workspace Customizations & Agent Rules

## Git Branch & Commit Policy
- **NEVER touch, commit to, or push to the `main` branch.**
- The `main` branch is the primary backup branch and must remain untouched.
- All feature development and bug fixes MUST be executed exclusively on the `dev` branch.
- **NEVER execute `git commit` or `git push` without explicit user permission.** Always ask the user and receive confirmation before committing or pushing changes.

## Feature Truth & Deprecated Architecture Rules
- **Per-minute call billing (male coin deductions and female call earnings per minute) was permanently removed in the August 1, 2026 pivot.**
- Calling access is governed exclusively by **unisex membership subscriptions (unlimited calling while subscribed)**.
- **NEVER mention per-minute coin deductions or call coin earnings** in any future project overview, architectural summary, or context document.
- **Dual-Balance Ledger**: Wallets consist of `spendable_balance` (purchased/promos, non-withdrawable) and `earned_balance` (Buddy rewards, withdrawable).
- **Buddy Lifecycle**: Chat unlocks immediately upon acceptance; OTP is strictly proof of the real-world meetup and triggers the 50-coin reward to `earned_balance`.
